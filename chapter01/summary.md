# Chapter 1 — The Machine Learning Landscape

## Key Concepts

### What is Machine Learning?
Machine Learning (ML) is the science of teaching computers to learn from data and make predictions or decisions without being explicitly programmed.

### Types of ML
- **Supervised Learning:** Predict outcomes from labeled data (e.g., regression, classification)  
- **Unsupervised Learning:** Find patterns in unlabeled data (e.g., clustering, dimensionality reduction)  
- **Reinforcement Learning:** Learn through trial-and-error feedback from an environment

### Key Terminology
- **Features / Attributes** — Input variables describing the data  
- **Labels / Targets** — Output variable the model predicts  
- **Training Set / Test Set** — Datasets for learning and evaluation  
- **Model / Algorithm** — The method used to make predictions  
- **Hyperparameters** — Settings that control model behavior

### Typical ML Workflow
1. Collect and explore data  
2. Preprocess and clean data  
3. Choose a model  
4. Train the model  
5. Evaluate model performance  
6. Tune hyperparameters  
7. Deploy the model

### Common Metrics
- **Classification:** Accuracy, Precision, Recall, F1-Score  
- **Regression:** RMSE, MAE, R²  

### Pitfalls & Considerations
- Overfitting vs. Underfitting  
- Bias-Variance tradeoff  
- Importance of data quality and representativeness
